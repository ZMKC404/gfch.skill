# 社群写作：喜报体系、月度回顾、招生社群体、结尾 CTA

正例均为语料原文短引（id 已核验），反例为 AI 腔对照（非原文）。总纪律：喜报可以热烈，但数字合规（见 data-discipline.md），CTA 不承诺收益。

## 喜报体

喜报是一串"有朋友……了："排比，每条一句，句尾本该跟一张截图，文字只负责指认事实。
- 正例（排比条目）："有朋友日收入破千美元了："（gefei-00005）；"有朋友9月做的两个网站，在10月份都快要UV破万了"（gefei-00005）；"还有朋友新站上线就喜获大量外链"（gefei-00005）
- 能披露的给个位，不能披露的明说："还有个月入破千的新朋友暂时不便透露"（gefei-00005）
- 喜报最后一条必落到自己身上，且带回馈动作："哥飞公众号广告主收入突破500元"（gefei-00005，后文接"已经在社群里全部发红包回馈给大家了"）
- 单人群友喜报文：标题带精确数（"群友新站上线9天拿到11030个独立访客"，gefei-00527），正文讲"他是怎么做到的"方法链
- 反例（AI 腔对照）："恭喜学员们取得优异成绩！大家的努力得到了回报，未来可期！"（没有一个可查的数）

## 月度回顾

结构固定（参照 gefei-00005 全篇）：
1. 开场近况一句："10月过去了，我很怀念它"（gefei-00005）
2. "**一、喜报**"（gefei-00005）分级罗列：日入千刀的 → 月入千刀的 → UV破万的 → 刚上第一个网站的——按成绩从高到低，最末档也要夸（"大家都是好样的"，gefei-00005 标题）
3. 自己的账号数据：关注数前后对比带个位（"公众号关注人数从月初的12061增涨到了14326"，gefei-00005）
4. 感谢 + 本月文章/链接复述块

## 社群样板间（招生段固定四段式，语料中整段反复复用）

1. **报价与余位**："一群已经有469位朋友了，也就是只剩31个位置了，目前价格888元"（gefei-00190）——写新稿时人数/价格/群数全部【待填：当前社群数据】，禁止沿用旧数或编造
2. **自问自答定位**："这是一个什么社群呢？是一个执行力十足，不断有报喜的好消息传来的社群。"（gefei-00197）
3. **话题清单**：8 条"1、建站基础，如何快速做一个网站；"式分号连排（gefei-00197）
4. **喜报链接块**：挂 4-8 条历史喜报文章

## 预置反方 → 反驳（招生段的核心防质疑结构）

先替读者把最大质疑说出口，再用"因为"正面拆掉。
- 正例："一句话介绍，这是一个教你出海做网站赚美元的社群"（gefei-00018），接"因为哥飞不是教你做一个类似的社群去赚别人的钱"（gefei-00018）
- 更彻底的做法是 FAQ 自问自答连发，连最难听的质疑都自己提："13、说破天，你还不是想赚社群费用？"（gefei-00176）
- 直白承认收费动机："是的，哥飞不是圣人，做不到社群也完全免费"（gefei-00176）

## 反向招生（劝退式，高级用法）

- 正例："还没加群的朋友，不建议立即加群"（gefei-00176，劝先跟养网站防老系列教程走一遍再考虑）
- 适用场景：读者是纯新手、或当月喜报数据不够好看时。先给免费路径，再谈付费，转化逻辑是"正反馈先行"。

## 结尾 CTA 模式清单（按需取用，通常 2-3 项组合）

- 收束句（必做，放在一切 CTA 之前）："好了，今天的文章就到这里了。"（gefei-00190）
- 确认句（教学文）："你学会了吗？"（gefei-00199）
- 转发请求："感谢你看到这里，如果觉得有用请转发出去，让更多人知道"（gefei-00448）
- 预告更新："明天我们聊第8步"（gefei-00197）
- 加微信：历史号码变过多轮（qiayue → GeFeiSvip → gefei55 → 361079），句式参考"微信搜索框，输入 361079"（gefei-00471）——写新稿时号码一律【待填：当前微信号】，不写历史号码
- 愿景收尾："让每一位朋友都能够慢慢有一个自己的小果园"（gefei-00197）；"养儿防老不如养网站防老"（gefei-00190）

## CTA 反模式

- 反例（AI 腔对照）："感兴趣的朋友赶快扫码咨询，名额有限，先到先得，错过再等一年！"（施压式饥饿营销，哥飞不这么写——余位是陈述事实，不是逼单）
- 反例（AI 腔对照）："加入我们的社群，你将获得价值99999元的超值资源大礼包！"（价值包装话术 + 收益暗示，全禁）
- 不虚构余位紧迫感、不编喜报、不在 CTA 段出现任何收益承诺数字。
