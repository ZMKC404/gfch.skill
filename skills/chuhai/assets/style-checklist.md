# chuhai 发布前自检表

> 用法：逐项勾选，全部可机械判定。任何一项不过 → 回对应 reference 修；涉数字或来源人物的项，素材查无 → 【待填：需回听核实】并列入交付清单，视为合规（占位不是 FAIL，编造才是 FAIL）。

## 标题与导读

- [ ] 1. 标题为冒号二段式：含冒号"："，前半是数字/事件/悬念钩子，后半含承诺词（拆解/还原/蓝图/SOP/横评/实战/复盘/展望/亲述）。
- [ ] 2. 标题里的每个数字都能在素材中找到出处；查无 → 改标题或【待填】。
- [ ] 3. 有 `### 导读`，70-130 字，2-3 句。
- [ ] 4. 导读写明来源人物 + 场合（谁 + 哪场对谈/视频），无"某专家/最新一期"式模糊来源；素材查无来源人物 → 【待填：需回听核实】占位即合规。
- [ ] 5. 导读末句有收口（宣言句/价值陈述/最大看点任一），不是"我们来看看吧"式套话。

## 结构

- [ ] 6. 正文第一段以"当你……"或"想象一下，你……"开场。
- [ ] 7. `####` 大节数量 4-8 个。
- [ ] 8. 编号小节用阿拉伯数字"1. / 2. / 3."，无"其一/其二/第一部分"。
- [ ] 9. 每个 ##### 小节/要点组四件套齐全：观点 → 数据 → 案例 → 落点（启发/避坑/实操细节）。
- [ ] 10. 有显式收束节：编号行动清单（3-4 条）或加粗"结论"段。
- [ ] 11. 标题/导读/节名的数字承诺与正文实际条目数一致（说 N 条能数出 N 条）。

## 数据与引用

- [ ] 12. 数字溯源零违规：每个数字可溯源至素材或已【待填】；同数字原样复现 ≤2 次（不复读凑密度）；素材-rich 时自然达到语料量级（13-60 处/篇），稀疏时不硬凑。
- [ ] 13. 至少 1 个案例带金额/收入数字锚点（如 $X MRR）。
- [ ] 14. 素材中未出现的数字、结论、引语均以【待填：需回听核实】占位，0 例外。
- [ ] 15. 单处连续引用 ≤50 字，无成段搬运原文。
- [ ] 16. "惊人倍数"类数据已标注来源或降级为条件式表述；无"数据显示/据说"式无主断言。

## 声音与语言

- [ ] 17. 全篇无拆解者第一人称（"我/我们"），仅存在于转述引语与视频作者自述。
- [ ] 18. 英文术语首现有中文译名或英文括注；行业缩写（MRR/CAC/SaaS 等）未翻译；品牌人名保留英文。
- [ ] 19. 无整段英文叙述（术语/缩写/引语除外）。
- [ ] 20. AI 腔黑名单零命中：首先/其次/综上所述/让我们/值得注意的是/随着…的发展/干货满满/拭目以待/各有优劣按需选择。
- [ ] 21. 问句全篇 ≤2（导读看点预告可用）。
- [ ] 22. 情绪形容词（残酷/疯狂/惊人/血淋淋/窒息/尸检）单篇合计 ≤4 次。

## 排版与清洗

- [ ] 23. 粗体高亮 14-43 处，覆盖数据断言/判语金句/术语首现/列表引导词（至少三类）。
- [ ] 24. 无转录噪音残留：`##### #####`、`==**…**==`、`****` 四星破损、`75_` 式残缺、星号内侧空格、可疑拼写（Weightlist 类）。
- [ ] 25. `* ` 列表项 ≥3，列表为正文主体，无 300 字以上连续大段。
- [ ] 26. 全文简体中文，1800-2400 字（口径：不含标点与空格的字符数，只按此口径判一次）。
