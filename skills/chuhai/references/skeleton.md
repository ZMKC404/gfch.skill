# 篇章骨架：三层标题 + 四件套单元 + 强制收束

> 依据 12 篇语料的结构统计（style-fingerprint.md）。结构一致性很高，可直接模板化；变体只在主体区的组织轴上。

## 通用骨架（自上而下）

```
# 标题（冒号二段式，写法见 headlines.md）
### 导读                 ← 70-130 字，2-3 句
#### 第一节：场景钩子      ← "当你……"开场（详见 voice.md）
#### 主体节 × 3-6        ← 核心区，内含 ##### 编号小节
#### 总结/结语/生存指南   ← 编号行动清单（写法见 action-lists.md）
### 标签                 ← 可选，语料仅 4/12 有
```

## 逐层规范

### 1. `### 导读`（12/12 全有，缺它不成立）

三件套，一句都不能省：

1. **来源人物**：谁 + 什么场合。正例："一名 41 岁的建筑师转型独立开发者"（chuhai-00002）。反例：只写"最近有个很火的视频"；语料 00000/00001 的"核心分析师""最新对谈"不给名，是指纹点名的来源模糊化毛病，别学。
2. **卖点预告**：2-3 个看点，用问句或数字。正例："涵盖 11 Labs 4亿美金 ARR 的增长逻辑"（chuhai-00001）。看点数字必须与正文对得上。
3. **价值定位末句**：导语末句必须收口，可以是宣言、价值陈述或最大看点；"这不仅是X，更是Y"式宣言语料 5/12（00001/00002/00004/00005/00011），置于导读末句的仅 2/12（00001、00011），是加分项不是硬性件。正例："这不仅是预测，更是一份 AI 时代的生存与套利指南。"（chuhai-00001）。反例：导读末句落在"我们来看看吧"。

元话语动词固定用"本文深度拆解/复盘/还原了……"，把"看视频"转写成"读文章"的姿态摆明：正例"本文深度复盘了 2025 年末 AI 界的关键转折点"（chuhai-00009）。

### 2. `####` 大节：4-8 个

- 第一节几乎必为场景钩子（11/12 以"当你……"开头），第二拍甩反差数据或核心冲突。
- 节名格式：主题词 + 冒号 + 判断/悬念。正例："算力霸权的'无限金钱'游戏：OpenAI 与 Nvidia 的深度捆绑"（chuhai-00007）。
- 末节为收束，节名直接带承诺更好："避坑指南：给 AI 个体商业者的三条建议"（chuhai-00000）、"给'一人公司'开发者的生存指南"（chuhai-00002）。

### 3. `#####` 编号小节：全篇 3-9 个

- 编号用阿拉伯数字："1. 传统 SaaS 的'护城河'正在干涸"（chuhai-00000）。不用"其一/其二"，不用"第一部分"。
- 每个小节/要点组是同一个循环：**观点 → 数据 → 案例 → 落点（启发/避坑/实操细节）**。落点缺失 = 该小节白写。
- 判语收尾是小节标配：把案例抽象成可复用的道理，如"**商业竞争的本质是阶梯式的资源积累**"（chuhai-00011，原文划线）。

### 4. 收束节（缺它 = 半成品）

- 7/12 收束为"给个体的 N 条建议"编号清单，N 的众数是 3；写法见 action-lists.md。
- chuhai-00000 例外型：无清单，用加粗"结论：2026 年的赢家，不是……"段落收尾——仅当素材实在给不出可执行动作时才用，且每个信息单元仍须带落点。

### 5. `### 标签` 行：可选

仅 4/12 有（chuhai-00002、00005、00006、00010）。要加就 4-5 个话题标签，格式如"#独立开发 #Steam 运营 #变现复盘"（chuhai-00002）。默认不加，除非用户账号惯用。

## 12 篇结构变体速查（骨架不变，轴不同）

| 组织轴 | 语料 | 主体区长什么样 | 什么时候学它 |
|---|---|---|---|
| 观点轴（默认） | 00000/00001/00004/00007 | 洞察→证据→启发，案例一段带过 | 观点输出型访谈 |
| 维度轴 | 00005 | "维度一：现金流（Cash Flow）—— 谁拿到了主动权？"式逐维对比 | 两套方案横评 |
| 策略轴 | 00008 | "策略一：等待名单（Weightlist）—— 制造稀缺与预热验证"，每策略配案例数字锚点（$61,000 MRR 式） | 增长方法合集 |
| 漏斗轴 | 00010 | 避坑清单→进阶备选→核心推荐，负面清单打头 | 工具横评 |
| 事件轴 | 00009 | "1./2./3./4." 多事件并列汇编（该篇转录损伤多，只学轴不学句） | 一周多事件盘点 |
| 单案例尸检 | 00002/00003/00006 | 全文围绕一个失败/成功故事逐层拆，案例即结构 | 复盘型内容 |

## 体量与密度

- 单篇 1800-2400 字（口径：不含标点与空格的字符数）；`* ` 列表项每篇 3-19 个（均值约 12），列表为主、段落为辅。
- 核心观点单元（#####小节或等价要点组）3-9 个，均值约 5。
- 写超了先砍案例条目，不砍数字和收束清单。
